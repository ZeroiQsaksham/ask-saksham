## Ask Saksham - personal AI agent (this website)
A RAG-based AI agent that answers visitors' questions about Saksham.
- Tech: Python, FastAPI, LangChain, Groq (Llama), ChromaDB, FastEmbed, HTML/CSS/JS
- How it works: Markdown knowledge files are split by headings, embedded into vectors, stored in ChromaDB, and retrieved by semantic search. The LLM uses tool calling to decide when to search the knowledge base, share contact details or save a message for Saksham.
- GitHub: https://github.com/ZeroiQsaksham/ask-saksham
